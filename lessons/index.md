# آموزش Markdown

به دنیای فارسی خوش آمدید!

در این بخش، Markdown را از پایه یاد می‌گیریم.

## درس اول: آشنایی با Markdown

Markdown یک زبان نشانه‌گذاری ساده است که برای قالب‌بندی متن استفاده می‌شود.

### مثال‌ها

**متن ضخیم**

*متن مورب*

[این یک لینک نمونه است](https://example.com)

## تمرین

۱. یک عنوان بنویسید.

۲. یک متن ضخیم ایجاد کنید.

۳. یک لینک بسازید.
