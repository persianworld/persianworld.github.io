# دنیای فارسی — نمونهٔ اولیه با Vite

این پروژه یک نمونهٔ ساده است تا ساختار سایت را در VS Code ببینی. فایل‌های داخل `lessons/` با Markdown نوشته می‌شوند و با کتابخانهٔ `marked` به HTML تبدیل می‌شوند.

## برای اجرای پروژه

۱. ابتدا Node.js نسخهٔ LTS را نصب کن: https://nodejs.org/en  
۲. پوشهٔ پروژه را در VS Code باز کن.  
۳. از منوی Terminal، گزینهٔ New Terminal را بزن.  
۴. این دستور را اجرا کن:

```bash
npm install
```

۵. سپس اجرا کن:

```bash
npm run dev
```

۶. لینکی که ترمینال نشان می‌دهد (معمولاً `http://localhost:5173`) را در مرورگر باز کن.

## اضافه کردن درس جدید

داخل پوشهٔ `lessons` یک فایل جدید مثل `lesson-03.md` بساز و متن را با Markdown بنویس. وقتی سرور توسعه روشن باشد، Vite معمولاً تغییرات فایل‌ها را تشخیص می‌دهد و صفحه را به‌روزرسانی می‌کند.

## نکته دربارهٔ انتشار

در نسخهٔ منتشرشده، فایل‌های Markdown هنگام build در بستهٔ سایت قرار می‌گیرند. برای رساندن درس جدید به سایت آنلاین، باید نسخهٔ جدید را build و دوباره منتشر کنی؛ مگر اینکه بعداً سامانهٔ مدیریت محتوا یا روش بارگذاری آنلاین اضافه کنیم.
